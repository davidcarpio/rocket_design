1  Fin Design & Stability Fundamentals

1.1 Introduction

Fins are the primary means of ensuring passive aerodynamic stability on a rocket. When a rocket flies at a small angle of attack \(\alpha\) (i.e., it is slightly tilted relative to its velocity vector), aerodynamic forces act on its surfaces. Fins, placed at the rear of the rocket, generate a restoring moment that rotates the rocket back toward its flight path — much like the feathers on an arrow.

The key to understanding stability lies in two points:

  • Center of Gravity (CG): the point where the rocket’s mass is balanced. This is the pivot point around which the rocket rotates.
  • Center of Pressure (CP): the point where the resultant of all aerodynamic normal forces acts.
ImportantThe Stability Rule

For a rocket to be statically stable, the Center of Pressure must be located behind (aft of) the Center of Gravity. The distance between them, expressed in body diameters (calibers), is called the stability margin:

\[ \text{Stability Margin} = \frac{X_{CP} - X_{CG}}{d} \]

A stability margin of 1.0 to 2.0 calibers is generally considered ideal for model rockets. Less than 1.0 caliber is marginally stable; less than 0.5 is unstable.

The Barrowman equations (1966) provide an analytical method to compute the CP location for slender, finned rockets at small angles of attack. The specific formulas depend on the fin planform geometry chosen.

1.2 Fin Planform Geometries

Fin shape—or planform—directly impacts aerodynamic performance, structural behavior, and manufacturing complexity. The most common planforms used in rocketry are summarized below.

1.2.1 Taxonomy

Geometry Key Parameters Taper Ratio (\(\lambda\)) Character
Rectangular \(C_r\), \(s\) \(\lambda = 1\) Simple to build. Higher drag at transonic speeds
Delta \(C_r\), \(s\), \(\ell_m\) \(\lambda = 0\) Low drag, structurally stiff. Common in HPR
Clipped Delta \(C_r\), \(C_t\), \(s\), \(\ell_m\) \(0 < \lambda < 1\) Good all-around compromise — most popular for HPR
Trapezoidal \(C_r\), \(C_t\), \(s\), \(\ell_m\) \(0 < \lambda < 1\) General form; clipped delta is a special case
Elliptical \(C_r\), \(s\) N/A Minimum induced drag (same principle as Spitfire wings)

1.2.2 Shape Comparison

Use the sliders below to see all five planforms drawn to the same scale.

Code 
viewof comp_cr = Inputs.range([4, 20], {value: 10, step: 0.5, label: "Root Chord Cr [cm]"})
viewof comp_span = Inputs.range([3, 15], {value: 8, step: 0.5, label: "Span s [cm]"})
Code 
{
  // Derived parameters
  const cr = comp_cr;
  const s = comp_span;
  const ct_clipped = cr * 0.4;  // λ ≈ 0.4 for clipped delta
  const sweep_delta = cr * 0.7; // typical sweep for delta
  const sweep_clipped = cr * 0.5;

  const W = 700;
  const cellW = W / 5;
  const H = 180;
  const pad = 12;
  const scale = Math.min((cellW - 2 * pad) / cr, (H - 50) / s) * 0.85;

  const svg = d3.create("svg")
    .attr("viewBox", `0 0 ${W} ${H + 10}`)
    .attr("width", "100%")
    .style("max-width", `${W}px`)
    .style("font-family", "'Inter', 'Segoe UI', system-ui, sans-serif");

  const fins = [
    {
      label: "Rectangular",
      points: [[0,0],[0,s],[cr,s],[cr,0]],
      color: "#3b82f6"
    },
    {
      label: "Delta",
      points: [[0,0],[sweep_delta, s],[cr,0]],
      color: "#8b5cf6"
    },
    {
      label: "Clipped Delta",
      points: [[0,0],[sweep_clipped, s],[sweep_clipped + ct_clipped, s],[cr,0]],
      color: "#06b6d4"
    },
    {
      label: "Trapezoidal",
      points: [[0,0],[cr*0.3, s],[cr*0.3 + cr*0.5, s],[cr,0]],
      color: "#f59e0b"
    },
    {
      label: "Elliptical",
      points: null, // handled separately
      color: "#ef4444"
    }
  ];

  fins.forEach((fin, i) => {
    const g = svg.append("g")
      .attr("transform", `translate(${i * cellW + cellW/2}, ${H - 15})`);

    if (fin.points) {
      // Polygon fins
      const pts = fin.points.map(([x,y]) =>
        `${(x - cr/2) * scale},${-y * scale}`
      ).join(" ");

      g.append("polygon")
        .attr("points", pts)
        .attr("fill", fin.color)
        .attr("fill-opacity", 0.3)
        .attr("stroke", fin.color)
        .attr("stroke-width", 2);
    } else {
      // Elliptical fin
      const nPts = 60;
      const ellPts = [];
      for (let j = 0; j <= nPts; j++) {
        const y = (j / nPts) * s;
        const chord = cr * Math.sqrt(1 - (y/s)*(y/s));
        ellPts.push([(chord/2) * scale, -y * scale]);   // right edge
      }
      // Mirror for full shape
      const fullPts = [];
      for (let j = 0; j < ellPts.length; j++) {
        fullPts.push(ellPts[j]);
      }
      for (let j = ellPts.length - 1; j >= 0; j--) {
        fullPts.push([-ellPts[j][0], ellPts[j][1]]);
      }
      const pathD = "M " + fullPts.map(p => p.join(",")).join(" L ") + " Z";

      g.append("path")
        .attr("d", pathD)
        .attr("fill", fin.color)
        .attr("fill-opacity", 0.3)
        .attr("stroke", fin.color)
        .attr("stroke-width", 2);
    }

    // Body tube line (root)
    g.append("line")
      .attr("x1", -cr/2 * scale - 5).attr("y1", 0)
      .attr("x2", cr/2 * scale + 5).attr("y2", 0)
      .attr("stroke", "#64748b")
      .attr("stroke-width", 1.5)
      .attr("stroke-dasharray", "4,3");

    // Label
    g.append("text")
      .attr("x", 0).attr("y", 16)
      .attr("text-anchor", "middle")
      .attr("fill", fin.color)
      .attr("font-size", 11)
      .attr("font-weight", "600")
      .text(fin.label);
  });

  return svg.node();
}
Note

The dashed line represents the body tube surface (fin root). All fins share the same root chord and span for direct comparison.

1.3 Design Trade-offs

Choosing a fin geometry is a multi-objective design decision. The table below summarizes the key engineering trade-offs:

Criterion Rectangular Delta Clipped Delta Trapezoidal Elliptical
Induced Drag High Medium Medium Medium Lowest
Structural Stiffness Low Highest High Medium Medium
Flutter Resistance Poor Best Good Medium Medium
Ease of Manufacture Easiest Easy Easy Easy Difficult
Weight Heaviest Light Medium Medium Light
CP Predictability Exact Exact Exact Exact Good
TipRule of Thumb

For a first rocket, clipped delta or trapezoidal fins offer the best compromise. For competition rockets optimizing drag, elliptical fins are theoretically optimal (analogous to elliptical wing loading in aircraft — cf. the Supermarine Spitfire). Delta fins excel when flutter resistance at high Mach is critical.

1.4 Barrowman Framework Overview

Regardless of fin shape, the Barrowman method computes two quantities for each rocket component:

  1. Normal force coefficient derivative \(C_{N\alpha}\) — how much restoring force the component generates per radian of angle of attack
  2. Center of pressure position \(X_{CP}\) — where that force effectively acts

The total rocket CP is the \(C_{N\alpha}\)-weighted average of all component CPs:

\[ X_{CP,\text{total}} = \frac{\displaystyle\sum_i C_{N\alpha,i}\,X_{CP,i}}{\displaystyle\sum_i C_{N\alpha,i}} \]

The specific formulas for \(C_{N\alpha}\) and \(X_{CP}\) depend on the fin geometry. The following chapters derive them for:

  • Trapezoidal fins — the general case covering rectangular, delta, and clipped-delta planforms
  • Elliptical fins — requiring dedicated integral derivations

1.5 Assumptions & Limitations

The Barrowman method is valid under the following assumptions:

  1. Small angle of attack — the rocket flies at \(\alpha < 10°\), where normal force varies linearly with \(\alpha\).
  2. Subsonic, incompressible flow — Mach number \(Ma < 0.4\). No compressibility corrections are applied.
  3. Slender, axisymmetric body — the rocket is long and thin relative to its diameter.
  4. Sharp nose cone — blunt nose shapes may shift the CP forward from predicted values.
  5. No body lift — the standard Barrowman method neglects lift generated by the body tube itself. Modified methods (Galejs, Rogers) account for this.
  6. Rigid structure — no aeroelastic deformation of fins or body is considered.
